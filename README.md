# NovaTrade Web To App

Android WebView app untuk membuka:
https://petrovneee.github.io/Bitcoin/

## Build APK dari HP via GitHub
1. Upload semua isi folder ini ke repo GitHub baru.
2. Buka tab Actions.
3. Jalankan workflow `Build Android APK`.
4. Setelah selesai, download artifact `NovaTrade-debug-apk`.
5. Extract ZIP artifact, lalu install `app-debug.apk`.

## Catatan
Aplikasi membutuhkan internet karena membuka website online.
